# 示例输入输出

以下 4 段输入均为虚构示例文本，内置于 `src/data/eventAnalysisSamples.ts`，可在事件研判页一键填入。

## 接口格式

请求 `POST /api/analyze`：

```json
{ "mode": "extract", "projectId": "tazara", "text": "新闻文本" }
```

返回（字段结构）：

```json
{"is_risk_event":true,"primary_tag":"社会ESG舆情","secondary_tags":[],
 "signals":{"E":{"strength":0,"evidence":""},"S":{"strength":0,"evidence":""},
            "V":{"strength":0,"evidence":""},"C":{"strength":0,"evidence":""}},
 "confirmation":false,"places":[{"name":"","country":"","lat":null,"lon":null}],
 "event_date":null,"summary":"","confidence":0,"reason":""}
```

客户端随后计算并展示：L、预警等级、足迹面积 areaKm2、命中站点 station_hits、命中资产 asset_hits、复核原因 review_reasons；再以 `mode: "advise"` 请求得到 `warning`、`recommendations`（3–5 条）、`watch_signals`。

## 示例 1 · 社区阻断

> 【示例｜虚构新闻】2026年10月12日，赞比亚 Kasama 站附近社区因货运噪声与就业安排组织集会。居民在铁路货运出入口设置路障，造成当日上午两班货列暂缓发运。示例中的站点值班人员确认出入口受阻，铁路公司表示正与社区代表沟通。目前报道未提及人员伤亡。

一次线上运行结果：置信度 0.60，预警等级 **高危**，地缘政治风险压力指数 L = 0.700，影响足迹命中 13 个站点，影响范围约 26,650 km²。地点 Kasama 经内置地点库解析，信号引句均来自原文，并生成处置建议。

## 示例 2 · 法语通关扰动

> [Exemple fictif — aucune actualité réelle] Le 13 octobre 2026, à Mbeya en Tanzanie, un retard de livraison de carburant a immobilisé plusieurs locomotives de fret. À Tunduma, des transporteurs signalent aussi une file de camions en attente de contrôle douanier. Dans ce scénario fictif, le responsable de la gare confirme le retard du ravitaillement, mais ne confirme aucune fermeture de la frontière. Aucune manifestation ni violence n’est rapportée.

预期输出：中文摘要与判断依据；places 含 Mbeya、Tunduma，均可由地点库解析；因存在多个地点，仅计算首个地点并提示其余地点另行研判；原文未报道抗议或暴力，相应信号应为 0。

## 示例 3 · 非风险报道

> 【示例｜虚构新闻】2026年10月14日，坦赞铁路公司在坦桑尼亚 Dar es Salaam 站举办文化节，员工与社区居民观看音乐表演并参观铁路历史展。天气晴朗，客货列车按计划运行。报道未提及抗议、事故、政策收紧或任何运输中断。

预期输出：is_risk_event = false，不生成影响足迹，复核原因显示当前判定为非风险事件。

## 示例 4 · 地点不明（边界案例）

> 【示例｜虚构新闻】某非洲内陆小镇的居民因运输噪声举行抗议，有人称货物通行短暂受阻。消息没有披露国家、城镇、车站名称或经纬度，尚无运营方核实。现有信息不足以定位现场或判断是否影响坦赞铁路。

线上运行结果：置信度 0.30，places = []。系统不猜测坐标、不生成足迹，复核原因包括置信度低于 0.6 与地点无法解析，状态为 **需人工复核**，复核人员补充明确地点后可重新计算。
