# 使用说明

线上地址：<https://enterprise-overseas-safety.vercel.app>（推荐使用桌面版 Chrome / Edge 浏览器）

## 1. 登录

打开网址后进入登录页，点击 **企业端**，账号与密码任意填写即可进入系统。

## 2. 页面导览

左侧导航栏依次为以下页面：

1. **风险情绪指数**（首页）：非洲各国 PORI 指数热力地图。PORI 为国家内网格地缘政治风险压力水平的均值经对数归一化得到的 0–100 分值。点击国家可在侧边栏查看指数、趋势与 15 项解释维度。
2. **影响模拟器**：选择事件类型与发生位置，系统按成本距离扩散模型绘制影响足迹（沿铁路扩散更快、跨越国界附加成本），并列出受影响站点与资产。
3. **重点项目**：以坦赞铁路为示范项目，展示线路、站点及相关风险事件，按三大类十五项分类浏览。
4. **案例分析**：预警信息流与详情视图，展示证据链、置信度以及确认预警 / 标记误报等人工研判操作。
5. **数据中心**：本项目使用的新闻媒体与传统数据源目录。
6. **事件研判**：核心 AI 流程，见下节。
7. **AI对话**：演示模块，展示问答式风险咨询的交互形态。

## 3. 事件研判操作步骤

1. 在左侧导航进入 **事件研判**。
2. 在文本框粘贴一段新闻（10–6000 字符，支持中文、英文、法语、斯瓦希里语），或点击下方任一内置示例；项目选择 **坦赞铁路 TAZARA**。
3. 点击研判按钮。服务端调用大模型完成事件编码，一般在 30 秒内返回。
4. 查看结果：
   - **编码结果**：是否风险事件、主标签与次标签（15 项分类）、事件日期、摘要、判断依据、整体置信度。
   - **E/S/V/C 信号**：每项强度及原文逐字引句，可逐条核对依据。
   - **地点与地图**：地点解析来源（地点库 / 模型坐标），地图显示影响足迹与命中站点。
   - **指数与预警**：地缘政治风险压力指数 L、预警等级（无预警 / 关注 / 警惕 / 高危）、足迹面积、命中站点和物流资产列表。
   - **人工复核**：触发复核条件时显示需人工复核及原因，可人工修正标签、地点、是否风险事件后重新计算。
   - **建议行动**：生成预警语句、3–5 条条件性处置建议与后续待核实信号。

## 4. 四个内置示例

| 示例 | 内容 | 预期看到的结果 |
| --- | --- | --- |
| 示例 1 · 社区阻断 | 赞比亚 Kasama 站附近社区集会设路障，两班货列暂缓 | 正常研判：社会ESG舆情类风险事件，地点经地点库解析，生成影响足迹与项目预警及建议 |
| 示例 2 · 法语通关扰动 | 法语文本，Mbeya 燃料延误、Tunduma 通关排队 | 多语言理解；中文摘要；多个地点时仅计算首个可解析地点，并提示其余地点另行研判 |
| 示例 3 · 非风险报道 | Dar es Salaam 站文化节，列车正常运行 | 判定为非风险事件，不生成影响足迹 |
| 示例 4 · 地点不明 | 某内陆小镇抗议，无国家、城镇、坐标 | 低置信度、地点为空，不猜测坐标，转入需人工复核（边界案例） |

更多字段说明见 [示例输入输出](示例输入输出.md)，方法见 [提示词与工作流](提示词与工作流.md)。
