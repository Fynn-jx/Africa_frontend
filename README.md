# 非洲地缘空间情报与冲突预警平台

一个专业的、国际化的非洲地区风险情绪与事件追踪数据平台。

## 设计理念

- **国际化、权威、中立、极简、高级感**
- 摒弃传统的“极客黑客风”或“深色战情室风”
- 转向“高级智库/高管决策支持平台”的风格
- 高信噪比设计、大量留白、清晰的层级关系、渐进式信息披露

## 核心功能模块

### 1. 舆情风险情绪指数（非洲宏观风向标）

- 全景地图可视化，聚焦非洲大陆
- 基于 Leaflet 的轻量地图视图，使用 OpenStreetMap 底图聚焦非洲大陆
- 热力图展示各国风险指数（PORI）
- 岛屿国家锚点高亮（毛里求斯、塞舌尔、马达加斯加）
- 交互式国家详情侧边栏
- 90 天趋势分析和 14 维度雷达图

### 2. 智能冲突预警系统（决策信息流）

- 双栏布局：预警列表 + 详情视图
- 多级严重性分类（严重/警告/信息）
- 证据链展示（社交媒体、卫星监测、预测模型）
- 模型置信度可视化
- 人工研判功能（确认预警/标记误报/申请更多数据）

### 3. 影响范围模拟器（精密分析工具）

- 智能搜索和地理编码
- 事件类型选择（抗议/爆炸/武装冲突）
- 动态影响范围可视化
- 受影响人口统计
- 中资资产波及分析
- 关键基础设施识别

### 4. 坦赞铁路专属监控（微观传导追踪）

- 精确的铁路线路可视化
- 实时站点状态监控
- 路段中断风险评估
- 应急处置建议
- 关键联系方式
- 报告生成功能

## 视觉规范

### 色彩系统

- **背景色**: 纯白 (#FFFFFF) 和浅灰 (#F9FAFB)
- **品牌主色**: 联合国蓝 (#005BBB)
- **预警语义色**: 莫兰迪色系（柔和红、警示黄）

### 排版体系

- **字体**: Inter（现代无衬线字体）
- **层级**: 通过字重和灰度区分
- **数字**: 等宽数字字体（Tabular numbers）

### 设计元素

- 极简底图，去除繁杂地貌
- 弥散阴影替代实线边框
- 圆角卡片设计
- 微妙的动画过渡

## 技术栈

- **框架**: React 18 + TypeScript
- **路由**: React Router v7
- **样式**: Tailwind CSS v4
- **动画**: Motion (Framer Motion)
- **图表**: Recharts
- **地图**: Leaflet + React Leaflet + CARTO Light 底图
- **图标**: Lucide React
- **UI 组件**: Radix UI

## 开始使用

```bash
# 安装依赖
pnpm install

# 开发模式
pnpm dev

# 构建生产版本
pnpm build
```

## 项目结构

```text
/src
  /app
    /components
      - Navigation.tsx             # 顶部导航栏
      - Root.tsx                   # 根布局组件
      /map
        - LeafletMap.tsx           # Leaflet 地图封装组件
      - CountryDetailsSidebar.tsx  # 国家详情侧边栏
    /pages
      - RiskSentimentIndex.tsx     # 风险情绪指数页面
      - ConflictEarlyWarning.tsx   # 冲突预警页面
      - ImpactSimulator.tsx        # 影响模拟器页面
      - RegionalInsights.tsx       # 重点项目与区域洞察页面
      - DataSources.tsx            # 数据中心页面
    - App.tsx                      # 应用入口
    - routes.tsx                   # 路由配置
  /data                            # 前端演示数据与知识库
  /hooks                           # 数据加载 hooks
  /styles                          # 全局样式与主题
  /utils                           # 静态 GeoJSON 数据加载工具
```
